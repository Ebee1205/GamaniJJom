# GamaniJJom v0.1.0 Beta

**첫 번째 공개 베타를 소개합니다 🎉**

GamaniJJom(가만히쫌)의 첫 베타 버전을 공개합니다!

GamaniJJom은 **화면 캡처와 창 고정을 한 번에 도와주는 Windows용 가벼운 플로팅 툴바**입니다.
`v0.1.0`은 핵심 기능을 먼저 선보이고, 여러분의 의견을 듣기 위한 초기 베타 버전이에요.

## ✨ 주요 기능

### 1. 화면 캡처
- **애플리케이션 캡처:** 연결해 둔 프로그램 창만 쏙 캡처해요.
- **전체 화면 캡처:** 프로그램을 연결하지 않아도 화면 전체를 캡처할 수 있어요.
- **영역 캡처:** 원하는 부분만 지정해서 캡처해요.
  - 캡처 영역의 너비와 높이(px)를 직접 설정할 수 있어요.
  - 영역 크기를 잠그거나 해제할 수 있어요.
  - 캡처 영역의 위치를 고정(Pin)해 둘 수 있어요.

### 2. 창 고정 (Window Lock)
- 연결한 프로그램 창의 크기와 위치를 고정해서, 작업 중 의도치 않게 바뀌는 일을 막아 줘요.
- 잠금 상태는 필요할 때 언제든 켜고 끌 수 있어요.

### 3. 플로팅 툴바
- 작업 공간을 거의 차지하지 않는 작은 툴바예요.
- **점착 모드:** 툴바가 대상 프로그램 창에 붙어서, 창을 옮기면 함께 따라 움직여요.
- **비점착 모드:** 프로그램 연결 여부와 상관없이 원하는 위치에 자유롭게 놓을 수 있어요.
- 멀티 모니터 환경도 고려해서 만들었어요.

### 4. 마우스 기반 메뉴 (Radial Menu)
- 툴바에서 마우스 오른쪽 버튼을 누른 채 드래그하면 기능을 고를 수 있어요.
- 이어서 드래그하면 하위 메뉴로도 들어갈 수 있어요.
- 프로그램을 선택할 때는 창 위에 마우스를 올려 미리 확인한 뒤 확정할 수 있어요.

## 📥 다운로드 및 실행

1. 아래 **다운로드** 항목에서 Windows용 실행 파일을 내려받아 주세요.
2. 다운로드한 파일을 실행해요.
3. 캡처할 프로그램을 선택하거나, 연결 없이 전체 화면 캡처를 바로 사용해 보세요.
4. 플로팅 툴바에서 캡처와 창 고정 기능을 편하게 이용하세요.

### 📦 다운로드

| 파일 | 설명 |
|------|------|
| `GamaniJJom_v0.1.0.exe` | Windows용 실행 파일 |

> 📎 실행 파일은 이 글 하단의 **Assets**(또는 첨부파일)에서 받을 수 있어요.

> 🛡️ **실행 시 Windows 경고가 나타날 수 있어요.**
> 아직 베타라 서명되지 않은 파일이라 'Windows의 PC 보호' 또는 '알 수 없는 게시자' 경고가 뜰 수 있어요.
> 이 경우 **추가 정보 → 실행**을 눌러 진행해 주세요.

## 📖 사용 방법

### 1. 도구 메뉴 열기
툴바에서 **마우스 오른쪽 버튼을 누른 채** 원하는 도구 방향으로 끌어다 놓으면 돼요.

![도구 메뉴](이미지주소/00-tools.png)

| 방향 | 기능 |
|------|------|
| ↑ 위 | 창 변경 |
| ← 왼쪽 | 영역 캡처 |
| → 오른쪽 | 잠금 |
| ↓ 아래 | 더보기 |
| 가운데 클릭 | 캡처 |

---

### 2. 창 연결하기
**창 변경**으로 놓은 뒤 연결할 창을 고르는 방법은 두 가지예요.

**방법 ① 창 목록에서 고르기**
목록에서 대상 창을 선택하고 **연결**을 누르세요. 창 이름으로 검색할 수도 있어요.

![창 연결](이미지주소/02-connect-window.png)

**방법 ② 화면에서 직접 고르기 (오버레이)**
우클릭을 누른 채 **창 변경**으로 놓은 다음, 대상 창 위로 마우스를 옮기면 해당 창이 강조돼요. 원하는 창에서 **우클릭**으로 확정하고, 취소하려면 `Esc`를 누르세요.

![창 선택 오버레이](이미지주소/08-overlay-window-selection.png)

---

### 3. 창 캡처
창이 연결된 상태에서 중앙의 **카메라 버튼을 클릭**하면, 연결된 창이 PNG 파일로 저장돼요.

![창 캡처](이미지주소/01-window-capture.png)

---

### 4. 연결 해제 후 전체 화면 캡처
**창 변경 → 연결 해제**를 하면 툴바가 **모니터 아이콘**으로 바뀌어요. 이 상태에서 클릭하면 주 모니터 전체 화면이 저장돼요.

![전체 화면 캡처](이미지주소/09-disconnected-fullscreen-capture.png)

---

### 5. 영역 캡처
도구 메뉴에서 **영역 캡처**를 선택하고 드래그로 영역을 지정하세요.

- 모서리를 끌어 크기를 조절할 수 있어요.
- 상단 입력창에서 너비·높이(px)를 직접 입력할 수 있어요.
- 잠금·고정(Pin) 버튼으로 영역 크기와 위치를 고정할 수 있어요.
- 준비가 되면 **카메라 버튼**을 눌러 캡처해요.

![영역 캡처](이미지주소/06-region-capture.png)

---

### 6. 창 잠금
우클릭을 누른 채 **잠금**으로 놓으면 창의 위치와 크기가 고정돼요. 같은 방법으로 다시 선택하면 해제돼요.

![창 잠금](이미지주소/05-window-lock.png)

---

### 7. 툴바 점착 / 비점착
**점착**: 툴바를 창 가장자리로 끌어다 붙이면 반원 모양으로 바뀌고, 창을 옮길 때 함께 따라 움직여요.

![점착](이미지주소/03-attached.png)

**비점착**: 가장자리에서 떼어내면 원형으로 돌아와요. 창 연결은 그대로 유지되니, 원하는 위치에 자유롭게 놓고 쓰세요.

![비점착](이미지주소/04-detached.png)

---

### 8. 이미지 저장 경로 바꾸기
**더보기 → 설정 → 저장**에서 저장 경로를 직접 입력하거나 **찾아보기**로 고를 수 있어요. 파일명 접두어, 날짜 포함 여부, 캡처 후 동작(완료 알림, 클립보드 자동 복사)도 여기서 설정해요. 변경 후 **확인** 또는 **적용**을 눌러 주세요.

![저장 경로 변경](이미지주소/07-save-path.png)

## ⚠️ 알려진 문제 및 제한 사항

아직 초기 베타라서 몇 가지 부분이 완전히 안정되지 않았어요. 양해 부탁드립니다.

- 일부 프로그램에서는 창 잠금이 기대와 다르게 동작할 수 있어요.
- 멀티 모니터 환경에서 툴바의 위치나 표시 상태가 일정하지 않을 수 있어요.
- 프로그램의 창 상태나 실행 환경에 따라 창 선택과 캡처 동작이 조금씩 다를 수 있어요.
- 사용자 인터페이스와 조작 방식은 앞으로 바뀔 수 있어요.
